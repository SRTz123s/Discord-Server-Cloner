# Discord Server Cloner

Утилита для копирования структуры сервера Discord (каналы, категории, роли,
права, эмодзи) с одного сервера на другой через user-токен.

Интерфейс выполнен в стиле **ZapretGUI** (Fluent UI / qfluentwidgets):
тёмная тема, акцентный цвет, эффект Mica, левая навигация
(Клонировать / Поддержка / Настройки / О программе).

## Возможности
- Клонирование категорий, каналов, ролей, прав и эмодзи.
- Сохранение токена в программе (не нужно вводить каждый раз).
- Гибкие настройки клонирования (что копировать).
- Визуальные настройки: тема (тёмная/светлая/авто), цвет акцента, Mica.
- Страница «Поддержка» с ссылками на Telegram, GitHub и донат.

## Установка и запуск (из исходников)
Требуется Python 3.12 (на 3.13+ `discord.py 1.7.3` не работает — удалён `cgi`).

```bash
pip install -r requirements.txt
python main.py
```

## Запуск через .exe
Готовый исполняемый файл: `dist/DiscordServerCloner.exe`.

## Важно
- Клонер использует **user-токен** Discord (`bot=False`), поэтому
  требуется именно `discord.py 1.7.3`.
- Discord убрал возможность создавать серверы через бота — создайте
  пустой сервер вручную и укажите его ID как целевой.
- Использование user-токена может нарушать правила Discord. Используйте
  на свой страх и риск.
